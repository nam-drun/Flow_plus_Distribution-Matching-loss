# Why care?
We have figured out that most distribution matching losses could hunt for discretisation error (in theory). And in practice, by having pretrained flow model serving as a good initialisation during training, distribution matching loss could actually hunt for discretisation error in practice. Then, we also have figured out that among the choice of distribution matching losses, such as Frechet Distance, GAN Adversarial, and KL, KL works best. This carries 2 practical implications:
1. It might help us understand how RLHF helps in MDP in image generation (see Qwen-Image 2.0). Until someone proves that RLHF cannot hunt for discretisation error, this remains an interesting possibility to figure out.
2. Flow + KL loss could be more computational efficient than MDP + RLHF in image generation. 

# How does distribution matching loss hunt for discretisation error (in theory)
First, we want to establish the idea that modern diffusion/flow matching is about reconstructing trajectory using initial position $X_0$, velocity field $v(t, X_t)$ and integrating solver such euler, heun, or dormand-prince5(4). In high school physics, people have learn the idea that *distance = velocity x time*. The same idea applies for flow matching during sampling. If you use Euler, it is quite literally *next position = current position + velocity x time*, and you keep doing this until *next position* = $\hat{X}_1$, which is a generated image. 

In Flow Matching, you train neural network to learn ground truth velocity field via mean-squared error. So where is ground truth velocity field coming from? Simple, during training, you sample a random pair of endpoints $`\left\{X_0, X_1\right\}`$. Then you compute current position $X_t$ using noise schedule. E.g., if you use VP schedule from DDPM diffusion, then $X_t = \sqrt{1 - t^2}X_0 + tX_1$; if you use linear schedule from [JiT paper](https://arxiv.org/abs/2511.13720v1) then $X_t = (1-t)X_0 + tX_1$. Then given current position $X_t$, you take its derivative to get velocity field at current position $v(t, X_t)$. Again, this is a classical idea from high school physics where velocity = derivative of current position. Now, on paper velocity field in flow matching is the average of derivative of current position, i.e., $v(t, X_t) = \mathbb{E}[\dot{X}_t \mid X_t = x]$. People design velocity field in this way so that if there are multiple trajectories passing through the point $x$, we can still derive some ground truth velocity field to train the neural network. However, in practice, the ambient space has so many dimensions such that the chance of multiple trajectories intersecting each other is basically none. So $\mathbb{E}[\dot{X}_t \mid X_t = x] \approx \dot{X}_t$. In other words, so long that ambient space has high number of dimensions (which is practically always true in image generation), then you can think of flow matching like you think of trajectory *distance = velocity x time*.

Second, we want to establish a simple idea that discretisation error is just the difference between $X_1$ and generated $\hat{X}_1$. See $e_B^{disc}$ in the picture below ![the picture below 1](https://github.com/nam-drun/Flow_plus_Distribution-Matching-loss/blob/main/discretisation-error.png)

Also, we want to establish an idea that direction of discretisation error is consistent in term of direction and displacement. From this very same picture, if you look at direction and displacement between Base Continuous vs Base Euler; then look at direction and displacement between Perturbed Continuous vs Perturbed Euler, then you will see that their direction and displacement are the same. This is not a coincidence and we can analyse this using Alekseev-Grobner formula in a separate post. For the moment, what you need to know is that this idea leads to another crucial idea: you can further train the neural network to learn some perturbed velocity field from Perturbed Continuous trajectory such that the discretisation error itself can be utilised to reproduce the ideal $X_1$. We show this in the left plot in the picture above. This is essentially the intuition behind theorem 3.2 in [IMDE paper](https://arxiv.org/abs/2206.07335).

Why do distribution matching loss train network network to learn the left one, but not the right one?
Because discretisation error is consistent in both direction and displacement. This means that for every Base Continuous, there is only 1 correct Perturbed Continuous that could counteract discretisation error. Now looking at distribution matching loss like Frechet Distance, Adversarial GAN, or KL; there's nothing in any of those distribution matching losses that explicit train the network to learn correct Perturbed Continuous. And yet, we find that all 3 distribution matching losses can train the network to learn correct Perturbed Continuous to some extends. Why?
